# LatencyLab

本地前端请求链路预算实验室。这里的推演是可重复的时间估算，不会调用真实接口。

## 本地运行

- 运行时：Node.js `>=20 <21`
- 安装依赖：`npm ci`
- 开发预览：`npm run dev`
- 质量门：`npm run lint`、`npm run test`、`npm run typecheck`、`npm run build`

## 功能模块

1. 链路项目：新建、改名、切换与复制项目。
2. 请求编排：增删节点、设置依赖及耗时、超时、重试、失败和降级参数；依赖变成环时拒绝连线。
3. 时序推演：乐观、预期、保守三种波动假设；不限并发或设置并发上限；展示完成预算、排队等待和关键链路。
4. 越线扫描：设定目标完成时间与一至两个参数区间，按步长完整推演离散组合，定位首次越线的相邻采样点、前后关键链路和受影响最大的节点；可将临界前与越线点保存为两份方案快照。
5. 方案对比：保存当前图和计算结果，比较两份参数快照并恢复任一快照。
6. 本地项目区：管理、复制和删除项目，查看保存状态。

## 架构

`views` 只渲染状态并转发事件。功能 VM 将项目、节点、推演、越线扫描和方案用例分开编排；纯规则位于 `shared/domain`；Repository 依赖 IndexedDB Service，并写入版本化 localStorage 恢复副本。项目数据不会发到服务器。

扫描在浏览器主线程按小批次让出事件循环，并报告实时进度；取消或切换项目会作废整次扫描，不会用部分样本生成临界值。扫描默认最多完整计算 1000 个参数组合，区间反向、步长过大或链路存在校验错误时会在运行前给出明确反馈。

默认示例：会话校验和功能开关并发启动；资料与目录在会话后开始；个性推荐等待功能开关和资料。结果使用确定性预算：延迟波动取所选情境、超时截断单次耗时、失败概率决定重试次数期望，重试退避按 200ms 指数增长并封顶 2 秒。降级耗时按最终失败概率加权。并发上限使用稳定拓扑顺序做资源排队估算。
